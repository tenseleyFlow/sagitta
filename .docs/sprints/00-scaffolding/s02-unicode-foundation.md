# Sprint 2: Unicode Foundation

## Prerequisites

- Sprint 0 — `base.h` (`u8`…`u64`), arena/vec/bytebuf, `yew_log`,
  `YEW_BUG`, the one Makefile, and its promise that the *only* generated
  file checked in outside `build/` is `src/unicode/tables.c` — this
  sprint lands it and documents it.
- Sprint 1 — unit harness, assertion macros, `make test`,
  `scripts/bans.sh`, CI lanes. Its `make fuzz` hard-errors naming *this*
  sprint; this sprint replaces it with the real harness. Assumption
  beyond the index entry: `tests/unit/fixtures/` does not exist yet —
  this sprint creates it and owns `fixtures/unicode/` (Sprint 9 adds
  files there).
- Binding: `00-decisions.md` invariants 2 (no byte confusion; invalid
  UTF-8 round-trips losslessly), 5 (deterministic rendering), 7 (bespoke
  first); `01-architecture.md`'s `src/unicode/` layout and its law
  *"Conversions live in src/unicode/ and are the only place allowed to
  do width math."*

## Goals

Land the whole Unicode substrate **before any buffer exists**, because
invariant 2 is designed in, not retrofitted: a bespoke UTF-8 DFA decoder,
total over arbitrary bytes, rejecting overlongs, surrogates and
`> U+10FFFF` structurally (no post-hoc range checks anywhere); the
PEP-383-style lossless invalid-byte policy (U+DC80–DCFF escapes that
re-emit the original byte verbatim, making encode∘decode the identity on
*every* byte string); UAX #29 grapheme segmentation with a 2-byte
incremental state restartable from any boundary; UAX #11 + emoji width
with the ambiguous-width option; a two-level property trie generated by
`scripts/gen-unicode-tables` and checked in; and the fuzz harness Sprint
1 deferred here. No `TextBuf` exists, so every entry point takes a flat
`(const u8 *, size_t)`. `TextBuf`-flavored conversions (`yew_off_to_gcol`,
`Cursor`, marks) are Sprint 9; escape/control *glyphs and attrs* are
Sprint 5/15 (cell counts are pinned here); `Word_Break` for W mode is
Sprint 16 (trie bits reserved); case folding for regex is Sprint 20 (a
generator extension). Unicode version for 1.0 is pinned at **16.0.0**.

### 2. The UTF-8 DFA (`src/unicode/utf8.c`)

Twelve byte classes. Three continuation classes exist because exactly
four leads constrain their first tail (`E0`≥A0, `ED`≤9F, `F0`≥90,
`F4`≤8F); the cut points 0x90/0xA0 are the union of those constraints, so
three suffice and a fourth would only grow the table.

| # | Name | Bytes | Why its own class |
|---|---|---|---|
| 0 | `AS` | 00–7F | complete scalar in one byte; the ASCII fast path |
| 1 | `C8` | 80–8F | continuation; the only tail `F4` may take (caps at U+10FFFF) |
| 2 | `C9` | 90–9F | continuation; legal after `ED` (last non-surrogate) and `F0` |
| 3 | `CA` | A0–BF | continuation; legal after `E0` (kills 3-byte overlongs) |
| 4 | `IL` | C0–C1, F5–FF | never legal: C0/C1 are 2-byte overlong leads, F5+ encode `> U+10FFFF` |
| 5 | `L2` | C2–DF | 2-byte lead, unconstrained tail |
| 6 | `E0` | E0 | 3-byte lead, tail must be `CA` — rejects U+0–7FF overlongs |
| 7 | `L3` | E1–EC, EE–EF | 3-byte lead, unconstrained tail |
| 8 | `ED` | ED | 3-byte lead, tail must be `C8`/`C9` — **rejects surrogates** |
| 9 | `F0` | F0 | 4-byte lead, tail must be `C9`/`CA` — rejects U+0–FFFF overlongs |
| 10 | `L4` | F1–F3 | 4-byte lead, unconstrained tail |
| 11 | `F4` | F4 | 4-byte lead, tail must be `C8` — **rejects `> U+10FFFF`** |

Nine states. `ACC` is both *start* and *sequence complete*; `REJ` is
sticky and the driver resets it.

| state | AS | C8 | C9 | CA | IL | L2 | E0 | L3 | ED | F0 | L4 | F4 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| `ACC` |ACC|REJ|REJ|REJ|REJ| T1|T2a| T2|T2b|T3a| T3|T3b|
| `REJ` |REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|
| `T1`  |REJ|ACC|ACC|ACC|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|
| `T2`  |REJ| T1| T1| T1|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|
| `T3`  |REJ| T2| T2| T2|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|
| `T2a` |REJ|REJ|REJ| T1|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|
| `T2b` |REJ| T1| T1|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|
| `T3a` |REJ|REJ| T2| T2|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|
| `T3b` |REJ| T2|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|REJ|

**Law: the table is the only validator.** Overlongs, surrogates and
`> U+10FFFF` are unreachable states, not values filtered afterwards;
`utf8.c` holds no comparison against `0xD800`/`0x10FFFF` outside
comments. If you are adding one, the table has a bug. Cost: `256 + 9*12 +
12 = 376` bytes of `.rodata`, hand-written — twelve literal ranges, the
UCD generator is not involved in this table.

```c
static const u8 lead_mask[12] = { 0x7F,0,0,0,0, 0x1F, 0x0F,0x0F,0x0F,
                                  0x07,0x07,0x07 };
/* One byte in, one DFA step. Accumulate BEFORE branching: on a lead the
 * payload width comes from the class, on a tail it is the low 6 bits. */
static u8 step(YewU8Dec *d, u8 b) {
    u8 cls = u8_class[b], st = u8_next[d->state][cls];
    d->cp = (d->state == YEW_U8_ACC) ? (u32)(b & lead_mask[cls])
                                     : (d->cp << 6) | (u32)(b & 0x3Fu);
    return (d->state = st);
}
```

**Recovery rule (pinned).** On `REJ` the driver escapes the **first byte
of the failed sequence only** and restarts the DFA at the byte after it.
Pitfall: the "maximal subpart" advice belongs to U+FFFD *replacement*; we
*preserve*, and preservation is per byte or the round-trip law dies.
`E1 41` must yield escape(E1) then `A` — swallowing both loses an ASCII
letter, exactly the bug class invariant 2 exists to prevent.

### 3. `src/unicode/utf8.h`

```c
#define YEW_UTF8_MAX      4
#define YEW_U8_MAX_FLUSH  4       /* codepoints one pushed byte can yield */
#define YEW_CP_ESC_LO     0xDC80u
#define YEW_CP_ESC_HI     0xDCFFu

typedef struct {          /* incremental decoder; zeroed = ready         */
    u8  state, n;         /* DFA state; bytes buffered in `pend`         */
    u8  pend[YEW_UTF8_MAX];
    u32 cp;
    u32 out[YEW_U8_MAX_FLUSH];   /* results of the last push/finish      */
} YewU8Dec;

void yew_utf8_dec_init(YewU8Dec *d);
/* Feed one byte; returns how many codepoints landed in d->out[]. 0 while
 * a sequence is incomplete; up to 4 when an ill-formed run flushes as
 * escapes and the pushed byte then starts a valid scalar (F0 90 80 41). */
u8   yew_utf8_push(YewU8Dec *d, u8 b);
u8   yew_utf8_finish(YewU8Dec *d);   /* EOF: truncated tail -> escapes   */

/* One-shot over a flat buffer. TOTAL: never fails, never reads past
 * s+len, always consumes >= 1 byte, always writes *out. */
size_t yew_utf8_decode(const u8 *s, size_t len, u32 *out);
/* Codepoint ENDING at pos. Scans back <= 4 bytes then decodes forward —
 * a backward scan alone cannot tell truncated from valid. */
size_t yew_utf8_decode_prev(const u8 *s, size_t start, size_t pos, u32 *out);

/* Encode. Escapes emit their ORIGINAL BYTE (length 1). Returns 0 for a
 * non-escape surrogate or cp > 0x10FFFF — those cannot come from our
 * decoder, so 0 means the caller synthesized a bad scalar (Fletch's
 * \u{...} validation, Sprint 29, relies on this). */
size_t yew_utf8_encode(u32 cp, u8 out[YEW_UTF8_MAX]);
size_t yew_utf8_len(u32 cp);          /* 1..4; 1 for an escape; 0 bad    */

bool yew_utf8_is_escape(u32 cp);
u8   yew_utf8_escape_byte(u32 cp);    /* cp - 0xDC00                     */
u32  yew_utf8_escape_of(u8 b);        /* 0xDC00 + b; b >= 0x80 asserted  */

/* Load path (Sprint 8's FileMeta.had_invalid_utf8). */
size_t yew_utf8_validate(const u8 *s, size_t len);  /* first bad off|len */
bool   yew_utf8_is_boundary(const u8 *s, size_t len, size_t pos);
```

**The round-trip law:** for every byte string `x`, re-encoding the
codepoint sequence that `yew_utf8_decode` produces reproduces `x`
byte-for-byte. Exhaustive- and fuzz-tested (DoD 4, 5).

### 4. Lossless invalid bytes — policy and flow

Every byte ≥ 0x80 the DFA cannot place becomes `0xDC00 + byte`
(U+DC80–DCFF); bytes < 0x80 are always well-formed, so 128 slots cover
the hazard. The range is unambiguous because our decoder never produces a
surrogate from well-formed input (class `ED` forbids it). A file
literally containing `ED B2 80` decodes to *three* escapes and re-encodes
to those same three bytes — no collision, round-trip intact.

| Layer | Representation |
|---|---|
| file on disk | raw bytes, untouched |
| `TextBuf` storage (s7/s8) | **raw bytes** — s08 pins byte-verbatim storage |
| decoded codepoint stream | U+DC80–DCFF — transient, produced by the decoder, consumed by segmenter/width/render |
| save (s8) | raw bytes — a *no-op transform* |
| registers/clipboard (s12) | raw bytes; yank/put is byte-exact |
| Fletch strings (s31) | escapes preserved; string ops must not "clean" them |

Escapes exist only in the decoded stream, so the save path cannot corrupt
them — it has no re-encoding step at all. Stronger than "we re-encode
carefully": the dangerous code does not exist.

**Display (cell counts pinned here; glyph/attr in Sprint 5/15):** an
escape renders as `<XX>` — four cells, uppercase hex, under a dedicated
attribute (`YEW_ATTR_INVALID_BYTE`, named now, defined in Sprint 5).
Never U+FFFD, never blank, never the raw byte. Four cells rather than one
opaque glyph because the user must be able to *read* the byte to reason
about the file; "something is wrong here somewhere" is how people lose
data by re-saving. And no tidying (invariants 1 + 2): an editor that
improves a file it did not understand is a corrupter with good
intentions.

**Segmentation:** escapes take GCB class `Control`, so GB4/GB5 break on
both sides — an invalid byte is always its own cluster and never glues to
a neighboring base or accent. This is what Sprint 9's `motion_golden.txt`
row `0xFF 0x41 → 2 clusters` pins.

### 5. Grapheme clusters — UAX #29 (`src/unicode/grapheme.c|h`)

Extended grapheme clusters, rules in order; `×` = no break, `÷` = break:

| Rule | Pattern | Note |
|---|---|---|
| GB1 | sot ÷ Any | first call after `init` reports a boundary |
| GB2 | Any ÷ eot | the caller's loop condition |
| GB3 | CR × LF | CRLF is one cluster — s08 keeps `\r\n` in the buffer, s09 motion must not split it |
| GB4 | (Control \| CR \| LF) ÷ | also fires for escapes (§4) |
| GB5 | ÷ (Control \| CR \| LF) | |
| GB6 | L × (L \| V \| LV \| LVT) | Hangul jamo |
| GB7 | (LV \| V) × (V \| T) | |
| GB8 | (LVT \| T) × T | |
| GB9 | × (Extend \| ZWJ) | combining marks, skin-tone modifiers, VS |
| GB9a | × SpacingMark | |
| GB9b | Prepend × | |
| GB9c | Consonant [Extend\|Linker]\* Linker [Extend\|Linker]\* × Consonant | Indic conjuncts; needs `InCB` (UCD 15.1+) |
| GB10 | — | **retired** in Unicode 11 (E_Base/E_Modifier folded into Extend); the gap is deliberate |
| GB11 | ExtPict Extend\* ZWJ × ExtPict | emoji ZWJ sequences |
| GB12 | sot (RI RI)\* RI × RI | flag pairs |
| GB13 | [^RI] (RI RI)\* RI × RI | |
| GB999 | Any ÷ Any | default break |

Properties required: **Grapheme_Cluster_Break** (14 values below),
**Extended_Pictographic** (GB11), and **InCB** ∈ {None, Linker,
Consonant, Extend} (GB9c). InCB is stored, not derived from Extend — the
derivation has enough exceptions (ZWNJ, the Linker set) that deriving it
is how you ship a wrong conjunct.

```c
typedef enum { YEW_GCB_OTHER = 0, YEW_GCB_CR, YEW_GCB_LF, YEW_GCB_CONTROL,
    YEW_GCB_EXTEND, YEW_GCB_ZWJ, YEW_GCB_RI, YEW_GCB_PREPEND,
    YEW_GCB_SPACINGMARK, YEW_GCB_L, YEW_GCB_V, YEW_GCB_T, YEW_GCB_LV,
    YEW_GCB_LVT, YEW_GCB_COUNT } YewGcb;

typedef struct { u8 prev_gcb, flags; } YewGbState;  /* zeroed = sot */
enum { YEW_GBF_RI_ODD = 1u << 0,  /* odd run of RIs immediately before  */
       YEW_GBF_PICT   = 1u << 1,  /* live ExtPict Extend* chain (GB11)  */
       YEW_GBF_INCB_C = 1u << 2,  /* live Consonant [Ext|Linker]* (GB9c)*/
       YEW_GBF_INCB_L = 1u << 3 };/* ...and a Linker has been seen      */

void yew_gb_init(YewGbState *st);
/* Break BEFORE cp? Then absorbs cp. This is the whole segmenter. */
bool yew_gb_boundary(YewGbState *st, u32 cp);

size_t yew_gb_next_bytes(const u8 *s, size_t len, size_t pos);
size_t yew_gb_prev_bytes(const u8 *s, size_t len, size_t pos);
size_t yew_gb_count_bytes(const u8 *s, size_t len);

/* cells is 0..4, or YEW_CLUSTER_TAB (255) for a lone U+0009 — the caller
 * owns tab stops (§6 rule 2), the tables must not guess a tabwidth. */
typedef struct { size_t off, len; u32 base_cp; u8 cells; } YewCluster;
/* Cluster + width in one pass — the renderer's entry point (Sprint 5). */
bool yew_cluster_next(const u8 *s, size_t len, size_t *pos, YewCluster *out);
```

State is **two bytes**, so Sprint 9 caches it per line and Sprint 5
restarts mid-viewport without rescanning. Sprint 9's `TextBuf`-flavored
`yew_grapheme_next` is a thin wrapper driving `yew_gb_boundary` from the
piece-chunk iterator; the flat entry points carry `_bytes` so the two
families never collide.

**Pitfall — backward segmentation is not the mirror of forward.** GB12/13
depend on the parity of an unbounded RI run and GB9c on an unbounded
`[Extend|Linker]*` run, so no fixed left-lookahead decides a boundary.
`yew_gb_prev_bytes` scans back to a **safe restart point** — GCB
Other/Control/CR/LF, and not RI, ExtPict, or InCB-Consonant — then
segments forward to `pos`, bounded at 64 codepoints or buffer start and
starting there anyway if the bound is hit (a 64-long RI run mis-parities
its last cluster: documented and tested, not a crash). The fuzzer asserts
`next(prev(p)) == p` at every boundary.

**ASCII fast path (required, not a later optimization).** If
`prev_gcb == YEW_GCB_OTHER`, `cp < 0x80`, and `cp` is not CR/LF/Control,
answer `true` with no table lookup. Sound because no ASCII codepoint is
Extend, ZWJ, SpacingMark, Prepend, RI, ExtPict, jamo, or InCB — every
suppressing rule needs a non-ASCII right side except GB3, excluded by the
guard. This is what makes the 100 MB-file budget reachable; DoD 11 gates
it.

### 6. Width — UAX #11 + emoji (`src/unicode/width.c|h`)

```c
typedef enum { YEW_EAW_N = 0, YEW_EAW_NA, YEW_EAW_A, YEW_EAW_W,
               YEW_EAW_F, YEW_EAW_H } YewEaw;

int    yew_str_width(const u8 *s, size_t len, u32 tabw);
/* Clip to <= max_cells without splitting a cluster; returns bytes kept.
 * s22/s23 label clipping calls this. */

```

Codepoint table, first match wins:

| # | Test | Cells |
|---|---|---|
| 1 | escape U+DC80–DCFF | 4 (`<XX>`, §4) |
| 2 | U+0009 TAB | −1 — caller advances to the next `tabw` stop |
| 3 | C0 control (U+0000–001F, U+007F) | 2 (`^X` form) |
| 4 | C1 control (U+0080–009F) | 4 (`<XX>` form) |
| 5 | U+00AD SOFT HYPHEN | 1 — explicit exception to rule 6; it is `Cf`, but glibc and terminals show it |
| 6 | zero-width: `Mn`, `Me`, `Cf`, conjoining jamo V/T (U+1160–11FF), ZWJ, VS15/VS16, U+200B–200F | 0 |
| 7 | EAW `W` or `F` | 2 |
| 8 | Emoji_Presentation = Yes | 2 |
| 9 | EAW `A` | `opts.ambiguous_wide ? 2 : 1` |
| 10 | anything else, incl. unassigned | 1 |

Cluster table, first match wins — a cluster's width is **not** the sum of
its codepoints':

| # | Cluster shape | Cells |
|---|---|---|
| a | starts with an escape | 4 |
| b | RI + RI (flag pair) | 2 |
| c | contains VS16 (U+FE0F) and base has `Emoji=Yes` | 2 — promotes keycaps (`1 FE0F 20E3`) and text-default emoji |
| d | contains VS15 (U+FE0E) | base width *ignoring rule 8* → 1 |
| e | contains ZWJ and any ExtPict | 2 — a family is one cluster of width 2, not the sum of its people |
| f | otherwise | width of the base (first non-Prepend cp); marks add 0 |

Skin-tone modifiers (U+1F3FB–1F3FF) are `Extend`, so they join under GB9
and add 0 by rule f: `👍🏽` is 2 cells.

**The honest note on terminal disagreement.** No escape sequence asks a
terminal how wide it thinks a codepoint is, and terminals genuinely
disagree (ambiguous-width CJK, new emoji, unassigned ranges). Pin: follow
UAX #11 plus `Emoji_Presentation` (the wcwidth-modern reading), expose
exactly one knob — `ambiguous_wide`, wired to config in Sprint 36 for
CJK-locale users — and never consult the runtime locale. What makes this
survivable: Sprint 5's renderer emits explicit cursor positioning per
cell run instead of trusting the terminal's cursor advance, and Sprint 22
hit-tests clicks through *our* tables. A width disagreement is then a
cosmetic overlap in one glyph, never a desync between model, screen, and
mouse.

**Pitfall:** `wcwidth(3)` is locale- and libc-dependent — two machines
would render the same buffer differently, breaking invariant 5 and the
pty goldens. Banned repo-wide from this sprint (§10).

### 7. The property trie (`src/unicode/tables.h`, `tables.c`)

One lookup serves segmenter and width: a **u16 packed record** per
codepoint.

| Bits | Field | Values |
|---|---|---|
| 0–3 | GCB class | 14 |
| 4–5 | InCB | None/Linker/Consonant/Extend |
| 6 | Extended_Pictographic | |
| 7–9 | EAW class | N/Na/A/W/F/H |
| 10 | zero-width (rule 6) | |
| 11 | Emoji | |
| 12 | Emoji_Presentation | |
| 13–15 | **reserved** | Sprint 16's Word_Break — regenerate, don't widen ad hoc |

Two-level trie with block dedup over U+0000–U+2FFFF, plus a sorted range
table above it (planes 3–16 hold a handful of uniform runs: CJK
extensions, tags, VS supplement, private use):

```c
#define YEW_TRIE_HI     0x30000u
#define YEW_TRIE_SHIFT  7               /* 128-codepoint stage-2 blocks */

extern const u16 yew_u_stage1[YEW_TRIE_HI >> YEW_TRIE_SHIFT];  /* 1536  */
extern const u8  yew_u_stage2[];        /* blocks of 128 palette indices */
extern const u16 yew_u_pal[];           /* the distinct packed records   */
extern const struct YewURange { u32 lo, hi; u16 rec; } yew_u_hi[];
extern const u32 yew_u_hi_len;
u16 yew_u_hi_lookup(u32 cp);            /* out-of-line, cold             */

static inline u16 yew_u_rec(u32 cp) {
    if (cp < YEW_TRIE_HI)
        return yew_u_pal[yew_u_stage2[
            ((size_t)yew_u_stage1[cp >> YEW_TRIE_SHIFT] << YEW_TRIE_SHIFT)
            + (cp & ((1u << YEW_TRIE_SHIFT) - 1))]];
    return yew_u_hi_lookup(cp);         /* binary search, <= 24 ranges   */
}
```

The palette indirection is what keeps this small: distinct *combinations*
of the fields number in the dozens, so stage-2 stores one byte per
codepoint instead of two, halving the dominant term.

| Array | Bytes |
|---|---|
| `yew_u_stage1` | 1536 × 2 = 3,072 |
| `yew_u_stage2` | ≤ 320 blocks × 128 = ≤ 40,960 |
| `yew_u_pal` | ≤ 64 × 2 = ≤ 128 |
| `yew_u_hi` | ≤ 24 × 12 = ≤ 288 |
| **total** | **≤ 65,536 (64 KiB)** |

```c
_Static_assert(sizeof(yew_u_stage1) + sizeof(yew_u_stage2)
             + sizeof(yew_u_pal)    + sizeof(yew_u_hi) <= 64 * 1024,
               "unicode tables exceed the 64 KiB budget (s02 DoD 2)");
```

**Pitfall — the Hangul syllable block.** U+AC00–D7A3 alternates LV/LVT
with period 28, defeating naive dedup. With 128-codepoint blocks
`lcm(128, 28) = 896`, so the pattern repeats every 7 blocks and dedup
recovers all but 7 of the 88. That is why the shift is 7; do not "tune"
it without re-measuring dedup.

### 8. `scripts/gen-unicode-tables.c` + `make unicode-tables`

Written in **C**, not python or shell: the repo already requires a C
compiler and nothing else (invariant 7), interpreter-version drift is a
reproducibility hazard, and regeneration must be byte-identical on any
host forever. Inputs are checked in under `ucd/16.0.0/` with a sha256
`MANIFEST` and the Unicode license text — regeneration is offline and
auditable in a diff.

| File | What we take |
|---|---|
| `UnicodeData.txt` | General_Category → zero-width (`Mn`,`Me`,`Cf`) and control classification |
| `GraphemeBreakProperty.txt` | the 14 GCB classes (default `Other`) |
| `emoji-data.txt` | `Emoji`, `Emoji_Presentation`, `Extended_Pictographic` |
| `EastAsianWidth.txt` | the 6 EAW classes |
| `DerivedCoreProperties.txt` | `InCB=Linker` / `Consonant` / `Extend` |
| `GraphemeBreakTest.txt` | copied verbatim to the fixtures dir (§Testing), not parsed by the generator |

Parsing pitfalls, each of which silently produces a *plausible* wrong
table:

- **`<..., First>` / `<..., Last>` pairs** in `UnicodeData.txt`. A
  line-per-codepoint parse loses every CJK ideograph and Hangul syllable
  — ~100k codepoints quietly become "unassigned, width 1". Handle the
  range convention explicitly; assert each pair is well-formed.
- **`@missing:` lines** define the default for unlisted codepoints, and
  for East_Asian_Width it is not uniform (some unassigned ranges default
  to `W`). Honor them; never assume `N`.
- **Comment tails / field shapes:** strip from `#`, trim; ranges are
  `LO..HI` or bare `LO`, hex without `0x`.
- **Property names must match whole-field.** `Extended_Pictographic` and
  `Emoji` both appear in `emoji-data.txt`; `strstr` matching silently
  conflates them.

Output: `src/unicode/tables.c` — generated header comment, the four
arrays, and a trailing comment recording the UCD version, each input's
sha256, and achieved sizes + dedup ratio, so a reviewer reads the budget
in the diff. Emission is deterministic: blocks in first-occurrence order,
palette in first-use order, no hash iteration anywhere.

```make
unicode-tables: $(BUILD)/gen-unicode-tables
	$< ucd/16.0.0 > src/unicode/tables.c
```

Run only when bumping the Unicode version. CI's `unicode` lane runs
`make unicode-tables && git diff --exit-code src/unicode/tables.c` —
committed file and generator can never drift. A 16.0.0 → 17.0.0 bump
post-1.0 is: replace `ucd/`, update `MANIFEST`, regenerate, re-pin the
GraphemeBreakTest count. Deliberately not taken before 1.0 so conformance
and corpus counts stay stable through the campaign.

### 9. Fuzz harness (`tests/fuzz/`) — Sprint 1's deferred promise

Bespoke, zero-dependency, deterministic. `fuzzlib.c|h`: xorshift64\* PRNG
(seed on the command line, printed in every failure report, so repro is
one command), corpus loader, mutators (byte flip, chunk delete/duplicate/
swap, truncate, splice two corpus entries, plus UTF-8-aware ones — split
a multi-byte sequence, flip a lead byte's class, inject a lone
continuation, inject `ED A0 80`), an `alarm(5)` watchdog, and a
binary-chop minimizer. Crashing inputs are minimized into
`tests/fuzz/crashes/`; a file there fails the build, and each becomes a
named fixture before its fix merges.

```make
fuzz: $(BUILD)/fuzz_utf8 $(BUILD)/fuzz_grapheme
	$(BUILD)/fuzz_utf8     --iters=$(FUZZ_ITERS) --seed=$(FUZZ_SEED)
	$(BUILD)/fuzz_grapheme --iters=$(FUZZ_ITERS) --seed=$(FUZZ_SEED)
```

Per-input invariants, enforced by the harness (not by the code under
test):

| # | Invariant |
|---|---|
| 1 | no crash, no ASan/UBSan report, no read past `s+len` |
| 2 | totality: every `yew_utf8_decode` consumes ≥ 1 byte; the scan ends exactly at `len` |
| 3 | **round-trip**: re-encoding the decoded sequence reproduces the input byte-for-byte |
| 4 | no decoded scalar in D800–DFFF except escapes, none > 10FFFF; a non-escape's re-encoded length equals bytes consumed (kills overlongs) |
| 5 | segmentation partitions: cluster lengths ≥ 1, sum to `len`, every boundary a codepoint boundary |
| 6 | incremental law: restarting `YewGbState` at any boundary reproduces the single pass's remaining segmentation |
| 7 | `yew_gb_next_bytes(yew_gb_prev_bytes(p)) == p` at every boundary |
| 8 | `0 ≤ yew_cluster_width ≤ 4`; `yew_str_clip` never exceeds `max_cells` nor splits a cluster |
| 9 | no hang (watchdog); same seed + corpus ⇒ identical mutation-sequence hash |

### 10. `scripts/bans.sh` additions

| Ban | Pattern | Why |
|---|---|---|
| locale-dependent width/decode | `wcwidth\|wcswidth\|mbrtowc\|wchar\.h\|setlocale\|iconv` over `src/` | locale/libc-dependent → nondeterministic rendering (invariant 5) and wrong widths |
| width math outside `src/unicode/` | `0x1F3FB\|0xFE0F\|0x200D\|EastAsian` outside `src/unicode/` | the architecture law, one conversion site (s22 DoD 7 re-checks `src/ui/`) |
| hand-edited tables | `tables.c` must carry the generated header comment | cheap tripwire; the CI `unicode` lane is the real gate |

### 11. Defer

- `TextBuf`-based conversions (`yew_off_to_gcol`, `yew_ccol_to_off`,
  `Cursor`, marks) → Sprint 9. Nothing here knows what a buffer is.
- Escape/control glyphs, `YEW_ATTR_INVALID_BYTE`'s definition, wide-cell
  continuation sentinels → Sprint 5; tab-stop/viewport consumption →
  Sprint 15. Cell *counts* are pinned here.
- `Word_Break` (UAX #29 words) for W mode was deferred to Sprint 16; trie
  bits 13–15 were reserved and emitted as zero at the Sprint 2 boundary.
  Sprint 16 subsequently delivered `src/unicode/wordbreak.*` and its
  conformance coverage, as formalized by amendment S59-A9.
- Full locale-neutral upper/lower case mappings (`UnicodeData.txt` plus
  unconditional `SpecialCasing.txt`) were deferred to Sprint 17, in a
  separate sparse table so mappings such as `ß` → `SS` can expand safely.
  Sprint 20 subsequently delivered regex-owned simple case folding from
  `CaseFolding.txt`, as formalized by amendment S59-A9.
- Normalization (UAX #15) → **never for 1.0**, and the reason is a
  feature: an editor that normalizes on load or save silently rewrites
  bytes the user never touched (invariant 1). Say so in the header; do
  not leave a stub.
- Line breaking (UAX #14) → not for 1.0; Sprint 15's wrap uses a simple
  whitespace/cluster rule. Bidi (UAX #9) → not for 1.0; RTL renders in
  logical order, stated plainly in the man page (Sprint 59).
- Unicode 17.0.0 → post-1.0 (§8).

## Testing Strategy

- **Unit — decoder** (`tests/unit/test_utf8.c`): every reject class
  driven once (`C0 80`, `E0 80 80`, `ED A0 80`, `ED BF BF`, `F0 80 80
  80`, `F4 90 80 80`, `F5 80 80 80`, bare `80`, `FF`); truncated
  sequences at buffer end for lengths 2/3/4, each prefix byte flushing as
  its own escape via `yew_utf8_finish`; the `E1 41` recovery case;
  `yew_utf8_decode_prev` from every offset of a mixed-width string.
- **Unit — exhaustive scalars**: all 1,112,064 non-surrogate codepoints
  satisfy `decode(encode(cp)) == cp` with lengths agreeing with
  `yew_utf8_len`; all 2,048 surrogates encode to 0 except the 128
  escapes, which encode to exactly their byte.
- **Unit — exhaustive short strings**: all 256 one-byte and all 65,536
  two-byte inputs round-trip byte-identically inside `make test`; the
  three-byte space (16,777,216) runs in the fuzz lane.
- **Conformance** (`tests/unit/test_gbtest.c`): parse
  `fixtures/unicode/GraphemeBreakTest.txt` (UCD 16.0.0, verbatim) —
  `÷`/`×` between hex codepoints, `#` comment tails — and assert our
  verdict at every position of every case; report
  `graphemebreaktest: N/N cases pass`. Pitfall: the separators are
  U+00F7/U+00D7 in UTF-8 — compare bytes, do not assume ASCII.
- **Golden corpus** (`fixtures/unicode/corpus.txt`, one case per line:
  `name|hex bytes|cluster byte-lengths|cell widths`): emoji ZWJ families
  (👨‍👩‍👧‍👦, 25 bytes → 1 cluster, 2 cells), profession ZWJ + VS16, flag pairs
  (🇦🇺 → 1; three RIs → 2; four RIs → 2), skin tones (👍🏽), keycaps
  (`1 FE0F 20E3`), CJK (漢, 2 cells), fullwidth forms, halfwidth kana,
  combining marks (`e`+U+0301; 10 stacked → 1 cluster, 1 cell), Hangul as
  L/V/T jamo and precomposed, a Devanagari conjunct (GB9c) plus a
  non-conjunct control, Prepend (U+0600), CRLF, lone CR, lone LF,
  isolated surrogate bytes (`ED A0 80`), every overlong form, truncated
  sequences at buffer end, `0xFF 0x41`, and a line mixing valid text with
  invalid bytes. ≥ 40 cases.
- **Width goldens** (`fixtures/unicode/width_golden.txt`): ≥ 60 rows
  covering all ten codepoint rules and all six cluster rules, run once
  per `ambiguous_wide` setting with expected columns for both.
- **Unit — segmenter and width** (`test_grapheme.c`, `test_width.c`): the
  corpus driven whole-string *and* restarted at every boundary (the
  incremental law); `yew_gb_prev_bytes` from every offset, including a
  case that trips the 64-codepoint bound; `yew_str_clip` at every
  `max_cells` from 0 to the string's width, asserting a wide glyph at the
  limit is dropped, never halved.
- **Fuzz**: `make fuzz FUZZ_ITERS=200000 FUZZ_SEED=1` in the gcc lane and
  under ASan/UBSan; nightly uses 2M iterations with a printed
  date-derived seed. Corpus seeds are the golden corpus plus every
  fixture byte string.
- **Perf** (`tests/perf/perf_unicode.c`, baselines committed): segment +
  width over 1 MiB each of ASCII, CJK, and emoji. ASCII gates the fast
  path (DoD 11); the others are recorded baselines until Sprint 56.
- **Determinism**: the CI determinism lane already double-runs `make
  test`; add `make unicode-tables` twice and diff the two outputs.

## Definition of Done

1. `make` green with gcc and clang, zero warnings under `-std=c11
   -pedantic -Wall -Wextra -Werror -Wvla`, including generated
   `tables.c` and `scripts/gen-unicode-tables.c`.
2. Table budget: the `_Static_assert` of §7 is present, the reported
   total is ≤ 64 KiB, and stage-2 dedup keeps ≥ 55% of blocks (generator
   prints both into `tables.c`'s trailing comment).
3. `make unicode-tables && git diff --exit-code src/unicode/tables.c` is
   clean from a fresh clone with no network; running it twice produces
   byte-identical output.
4. Round-trip law: all 256 one-byte and all 65,536 two-byte inputs
   re-encode byte-identically in `make test`; all 16,777,216 three-byte
   inputs pass in the fuzz lane; zero failures.
5. Exhaustive scalars: 1,112,064 codepoints round-trip; `yew_utf8_encode`
   returns 0 for all 1,920 non-escape surrogates and for `0x110000`; the
   128 escapes each encode to exactly one byte, `cp - 0xDC00`.
6. Conformance: `graphemebreaktest: N/N cases pass`, zero failures, N
   equal to the non-comment line count of the checked-in UCD 16.0.0
   `GraphemeBreakTest.txt`, N ≥ 600. The count is asserted, not merely
   printed.
7. Golden corpus ≥ 40 cases, width goldens ≥ 60 rows, all green in both
   ambiguous-width settings; every category named in Testing Strategy has
   at least one case.
8. `make fuzz FUZZ_ITERS=200000 FUZZ_SEED=1` exits 0 for both fuzzers,
   plain and under ASan/UBSan; all nine harness invariants checked per
   input; same seed twice ⇒ identical mutation-sequence hash;
   `tests/fuzz/crashes/` empty. `make fuzz` no longer hard-errors.
9. `grep -rn 'wcwidth\|wcswidth\|mbrtowc\|wchar\.h\|setlocale\|iconv'
   src/` returns nothing; `scripts/bans.sh` exits 0 with the three new
   rules active, each proven to fire by a seeded violation.
10. `utf8.c` contains no range comparison against `0xD800`/`0xDFFF`/
    `0x10FFFF` outside comments — rejection lives only in the transition
    table, and the file header says so.
11. Perf: segment + width over 1 MiB of ASCII in ≤ 5 ms on the dev
    machine (fast path proven live); CJK and emoji baselines committed
    under `tests/perf/baselines/`.
12. Deferred-surface lifecycle is explicit: Sprint 16 owns `yew_wb_*` and
    its word-break coverage, Sprint 20 owns the regex simple-fold entry
    point and its agreement corpus, and no normalization entry point exists;
    `grapheme.h`/`width.h` name the owning sprints and permanent non-goals.
13. `ucd/MANIFEST` lists all six inputs with sha256; `ucd/LICENSE` holds
    the Unicode license; `README.md` gains a paragraph on why
    `src/unicode/tables.c` is generated *and* committed (redeeming
    Sprint 0's promise).
14. ≥ 45 registered unit tests and ≥ 400 assertions across `test_utf8.c`,
    `test_grapheme.c`, `test_width.c`, `test_gbtest.c`; valgrind lane
    reports zero definite leaks; ASan/UBSan clean.
