YEW TUTOR 3/7 — EXECUTE MODE AND THE SHELL

E mode is yew's command language. A leading ! runs your shell, while a range
before ! filters buffer text through a command as one undoable edit.

[ ] ch03.t1 Open E mode with :.
[ ] ch03.t2 Cancel E mode with Esc.
[ ] ch03.t3 Run :set tabwidth=4.
[ ] ch03.t4 Recall that command with : then Up, and cancel.
[ ] ch03.t5 Sort the three fruit lines with :17,19!sort.
[ ] ch03.t6 Undo both the task mark and filter with 2u.
[ ] ch03.t7 Run the filter again from command history.
